# Open a pull request for a finished branch

## What this does

`implement-issue` opens its draft PR before any work lands. A branch built any other way — a fix
committed by hand, a spike that turned out right, or a fix `debug-issue` left sitting on the default
branch itself — needs a way to become a PR the way the kit expects. This skill is that way:
`/create-pr [#<issue>] [--draft]` takes the work off the default branch first when that's where it
sits, pushes it through the guard, decides ready or draft, and opens the PR through
[`../_shared/open-pr.md`](../_shared/open-pr.md) — the one home of the existence lookup, the title
gate and the create call. Then it hands off to `merge-pr`.

## Autonomy contract

Run **hands-off** once started. See
[ADR 0005](../../docs/adr/0005-the-lifecycle-skills-run-hands-off-triage-backlog-does-not.md) for the
decision scope: pick the reasonable default, state the assumption, keep going. Stop only for a
genuine blocker:

- `gh` not authenticated, or no push rights.
- A Step 2 refusal — a detached HEAD, a leftover `[DEBUG-` probe on the default branch, nothing
  ahead of it, a closed issue. Each one refuses before any write. A dirty tree no longer refuses —
  Step 2 commits it, through the guard.
- A PR already open for this branch or its issue: report it, open none.
- A guard exit that is not a success, or a readback that does not match — including
  `rewind-default.sh`'s exit 3 (the default is left ahead of `origin/$DEFAULT`, reported, never
  retried).

A red *Full test* is not a blocker. It opens a draft and says why, so nobody merges it by mistake.

## Checklist

Create a task per item and work them in order.

1. **Preconditions** — profile, `gh` auth, commit identity.
2. **Locate the work** — off the default branch first when that's where it sits, its issue, the
   refusals and the existing-PR lookup.
3. **Open** — guarded push, ready or draft, the body, the shared PR-open recipe, then rewind the
   default when Step 2 branched off it.
4. **Recap** — the shared closing shape ([`../_shared/recap.md`](../_shared/recap.md)), Next `/merge-pr #<pr>`.

Resume-safe: a re-run finds the PR an earlier run opened (the recipe's §1) and stops on it.
